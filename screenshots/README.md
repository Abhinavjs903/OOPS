# Gameplay Screenshots

Save genuine screenshots from your own successful program runs in this folder.

Suggested files:
- `gameplay.png` — start of a game / board after a few moves
- `invalid-move.png` — an occupied-cell or out-of-range move being rejected
- `winner.png` — completed game showing the winner
- `draw.png` — optional draw example

Do not use mockups as evidence of program execution.
